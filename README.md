# Syifani Adillah Salsabila — Portfolio

Personal portfolio for Syifani Adillah Salsabila, an Informatics Engineering student focused on cybersecurity, network infrastructure, cloud operations, DevOps, and technical support.

## Highlights

- Security monitoring project covering 663,762 alerts with Wazuh, Graylog, OpenSearch, MISP, and Docker
- Cloud-native Go4Beyond platform with 11+ containerized services
- Vulnerability assessment and Linux/server administration projects
- Experience and recognitions across SOI Asia, APNIC, APAN, APNG, and ICANN
- Downloadable ATS resume and recruiter-friendly contact links

## Technology

- Next.js 16
- React 19
- TypeScript
- Responsive CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev:vercel
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build:vercel
```

## Deploy to Vercel

Import this repository in Vercel. The included `vercel.json` selects the standard Next.js build automatically.
